# Equipment Rental Rangpur (Server)

Backend API for Equipment Rental Rangpur — a marketplace where owners list equipment for rent and customers browse, book, and pay online.

## Live URL
- Server: https://rangpur-rental-server.vercel.app

## Key Features
- Equipment CRUD, approval workflow, and server-side search, filter, sort
- Customer favorites and booking availability checks
- Stripe checkout session verification and payment logging
- Role-based access control (Customer, Owner, Admin) with JWT verification
- Admin and Owner dashboard analytics

## NPM Packages
`express`, `cors`, `dotenv`, `mongodb`, `jose`, `stripe`
